## Descripción

La tabla `civic_oficios_generados` lleva el historial de todos los documentos PDF producidos para un expediente. La nomenclatura federal es: `CURP_TipoDocumento.pdf` (HU-05).

## Tipos de documento (`TipoDocumentoEnum`)

| Valor | Descripción |
|---|---|
| `OFICIO_CANALIZACION` | Oficio de canalización inicial |
| `OFICIO_INCORPORACION` | Incorporación al programa |
| `OFICIO_CONCLUSION` | Alta definitiva — solo si horas cumplidas ≥ horas sentencia |
| `INFORME_INCIDENCIAS` | Reporte de incidencias acumuladas |
| `OFICIO_BAJA_DEFINITIVA` | Baja por acumulación de incidencias |
| `OFICIO_MODIFICACION_DIAS` | Ajuste de días por el juzgado |
| `F3_PLAN_TRABAJO` | Plan de trabajo firmado |
| `F4_CEDULA_INICIAL` | Cédula para reporte federal |
| `LISTA_ASISTENCIA` | Lista semanal de asistencia |
| `REPORTE_SEMANAL_GUIA` | Reporte del guía |

## Endpoints

### `POST /civico/oficios`
Registra un oficio generado (URL del archivo almacenado).

### `GET /civico/oficios/expediente/:expedienteId`
Lista todos los documentos de un expediente.

### `GET /civico/oficios/expediente/:expedienteId/paquete`
Descarga el ZIP con los archivos requeridos para la plataforma federal (HU-05, RF-016).  
<Warning>El paquete omite cualquier referencia a UMECAS — exclusivo del módulo Penal.</Warning>
