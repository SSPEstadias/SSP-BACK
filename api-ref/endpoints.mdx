## Beneficiarios (Shared)

| Método | Ruta | Descripción | Roles |
|--------|------|-------------|-------|
| `POST` | `/beneficiarios` | Registrar beneficiario | Admin |
| `GET` | `/beneficiarios` | Listar todos | Admin, Psicologo, TrabajoSocial |
| `GET` | `/beneficiarios/filtrar?unidad=HORAS` | Filtrar por módulo | Admin |
| `GET` | `/beneficiarios/:id` | Obtener por ID | Admin, Psicologo, TrabajoSocial |
| `PATCH` | `/beneficiarios/:id` | Actualizar | Admin |
