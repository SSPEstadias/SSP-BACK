## Requisitos previos

| Herramienta | Versión mínima | Uso |
|-------------|----------------|-----|
| Node.js | 20.x LTS | Entorno de ejecución |
| npm | 10.x | Gestor de paquetes |
| PostgreSQL | 15.x | Base de datos |
| Git | 2.x | Control de versiones |

---

## 1. Clonar el repositorio

```bash
git clone https://github.com/SSPEstadias/SSP-BACK.git
cd SSP-BACK
git checkout main
```

---

## 2. Instalar dependencias

```bash
npm install
```

---

## 3. Configurar variables de entorno

Crea un archivo `.env` en la raíz del proyecto con el siguiente contenido:

```env
# Base de Datos
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=tu_password
DB_NAME=reconecta_paz

# JWT
JWT_SECRET=tu_secreto_muy_seguro_aqui
JWT_EXPIRES_IN=8h

# Seed Admin (primer arranque)
SEED_ADMIN_PASSWORD=Admin1234
```

<Warning>
Nunca subas el archivo `.env` al repositorio. Ya está incluido en `.gitignore`.
</Warning>

---

## 4. Correr la aplicación

```bash
# Modo desarrollo (con hot reload)
npm run start:dev

# Modo producción
npm run start:prod
```

Al iniciar, el sistema ejecuta automáticamente el **Seeder** que crea el usuario `admin` si no existe.

---

## 5. Verificar que funciona

```bash
# Debe responder Hello World!
curl http://localhost:3000
```

Para probar la autenticación:

```bash
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"nomUsuario":"admin","contrasena":"Admin1234"}'
```

**Respuesta esperada:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```
